# モダン掲示板 ファイル構成書

## プロジェクトルート (c:/work/250315_PlanningSheet)

```
.
├── docs/                      # プロジェクトドキュメント
│   ├── project_specification.md  # プロジェクト仕様書
│   └── file_structure.md      # ファイル構成書
│
├── css/                       # スタイルシート
│   ├── style.css             # メイン掲示板のスタイル
│   └── tetris.css            # テトリスゲームのスタイル
│
├── js/                        # JavaScriptファイル
│   ├── main.js               # 掲示板機能のメインスクリプト
│   └── tetris.js             # テトリスゲームのスクリプト
│
├── .gitignore                # Gitの除外設定ファイル
├── index.html                # メインページ
├── messages.db               # SQLiteデータベースファイル
├── run_server.bat            # サーバー起動用バッチファイル
└── server.py                 # Flaskサーバーアプリケーション
```

## 各ファイルの役割

### ドキュメント

#### docs/project_specification.md
- プロジェクトの詳細仕様
- 機能仕様、技術仕様、データベース設計などの文書化

#### docs/file_structure.md
- プロジェクトのファイル構成
- 各ファイルの役割と説明

### フロントエンド

#### index.html
- アプリケーションのメインページ
- 掲示板とテトリスゲームのUI実装
- レスポンシブデザイン対応のHTML構造

#### css/style.css
- 掲示板機能のスタイル定義
- CSSカスタムプロパティによる配色管理
- レスポンシブデザインのメディアクエリ
- アニメーション効果の定義

#### css/tetris.css
- テトリスゲームのスタイル定義
- モーダルウィンドウのデザイン
- ゲーム画面のレイアウト
- ランキング表示のスタイル

#### js/main.js
- 掲示板機能のフロントエンド実装
- REST APIとの通信処理
- 投稿の表示と更新
- エラーハンドリング
- XSS対策

#### js/tetris.js
- テトリスゲームのロジック実装
- キー入力処理
- ゲーム状態管理
- スコア計算
- ランキング機能

### バックエンド

#### server.py
- Flaskサーバーアプリケーション
- REST APIのエンドポイント定義
- データベース操作
- CORSの設定
- セキュリティ対策

#### messages.db
- SQLiteデータベースファイル
- メッセージテーブル
- テトリススコアテーブル

#### run_server.bat
- Windowsでのサーバー起動用バッチファイル
- Flask開発サーバーの起動

### その他

#### .gitignore
- バージョン管理から除外するファイルの設定
- 一時ファイルやビルド成果物の除外
